# Security

RowDelta processes selected data locally. The built page blocks network connections and has no analytics, external scripts, or persistent app storage. Hosting still exposes ordinary page-request metadata to the host. Download and open the HTML offline for disconnected use. Exports may contain your data; review them before sharing. Browser extensions and compromised devices are outside the app's control.

This early release has automated tests and local browser checks, but no independent security audit. Use GitHub private vulnerability reporting if enabled. Otherwise ask for a private contact in an issue without posting sensitive details.
